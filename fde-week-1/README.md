# My Week 1 FDE Project

The goal of this project is to familiarize myself with the workflow of a
Forward Deployed Engineer (FDE).

## Week 1 Goals

- Understand the role and responsibilities of an FDE.
- Set up a productive development environment and workflow.
- Practice translating customer needs into clear technical requirements.
- Build and test a small working solution.
- Document progress, lessons learned, and areas for improvement.
